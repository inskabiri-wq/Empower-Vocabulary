Listening transcript - can you close it?

Loads transcript-collapse-frame.html (the real markup and the real stylesheets) in an iframe at each width, with the transcript OPEN, and asks one question: is there a visible control that closes it, and can a real tap reach that control? Media queries inside an iframe respond to the iframe's own width, which is what makes per-width testing possible.
